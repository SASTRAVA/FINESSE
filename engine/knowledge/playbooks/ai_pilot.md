# Responsible AI pilot

## Listen
- Map the workflow, users, source data, failure costs, and existing controls.
- Identify sensitive data and the approved model and hosting boundaries before a pilot.

## Shape
- Select a bounded, reversible use case with a human review point.
- Define a baseline, measurable success criteria, error handling, access controls, and a stop condition.

## Deliver
- Produce a pilot plan, test set, data-flow sketch, monitoring plan, and owner checklist.
- Do not send confidential information to an unapproved provider or claim that a pilot proves production readiness.
