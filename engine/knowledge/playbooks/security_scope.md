# Authorized security scope

## Listen
- Confirm the requester is authorized and document the assets, environments, dates, and exclusions.
- Gather existing architecture and control evidence without collecting credentials or unnecessary personal data.

## Shape
- Define a non-destructive review plan, evidence sources, severity model, communication path, and stop conditions.
- Separate validated findings from hypotheses and note limits in the available evidence.

## Deliver
- Provide prioritized findings, remediation options, owners, and retest criteria.
- No testing or exploit activity is implied by a scoping response; obtain explicit approval for any assessment.
